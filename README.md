# Inner — Личная Операционная Система

> Система для организации жизни, достижения целей и работы над собой.

## Как это работает

Эта система — твоя вторая память. Все файлы написаны в простом Markdown — читаемы, редактируемы, версионируемы через Git.

В начале каждой сессии с Claude я читаю эти файлы и понимаю, где ты сейчас находишься. Ты даешь команды, я обновляю файлы. Всё остается здесь, в твоем контроле.

## Структура

### 📋 `/profile` — Кто ты
- `about.md` — твои ценности, сильные стороны, что важно
- `/beliefs` — работа с убеждениями (негативные → позитивные)
- `identity.md` — кем ты хочешь стать

### ✅ `/tasks` — Система задач
- `inbox.md` — быстрые захваты (всё сюда сначала)
- `next.md` — следующие действия (фокус здесь)
- `someday.md` — когда-нибудь/возможно
- `/done` — архив завершенных задач

### 🎯 `/goals` — Цели
- `2025.md` — цели на год
- `/monthly` — помесячные цели и прогресс

### 🔄 `/habits` — Привычки
- `tracker.md` — отслеживание привычек

### 📝 `/journal` — Дневник
- `/daily` — ежедневные записи
- Рефлексия, мысли, инсайты

### 💡 `/notes` — Заметки и знания
- Идеи, обучение, второй мозг

## Команды (примеры)

```
Добавь задачу: позвонить маме
Покажи мои задачи на сегодня
Добавь негативное убеждение: я недостаточно умен
Покажи мои цели на месяц
Создай дневниковую запись за сегодня
Отметь привычку: медитация
```

## Философия

**Продуктивность** без осознанности = бег на месте
**Цели** без рефлексии = чужие цели
**Порядок** без продуктивности = красивая видимость
**Осознанность** без действий = философствование

Всё связано. Всё работает вместе.
