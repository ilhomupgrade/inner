## В работе

### 1. Рефрейм: От страха окончательности к данным (negative.md #1)

**Старое убеждение:**
"Если попробую по-настоящему и не получится - моя мечта умрет"

**Почему это не вся правда:**
- Один завершенный проект ≠ окончательный приговор всей мечте
- Текущая стратегия (саботаж) УЖЕ убивает мечту - медленно, но верно
- Я путаю "один эксперимент" с "вся жизнь"
- Не завершая, я не получаю данных. Без данных нет обучения. Без обучения нет прогресса
- Страх отказа больше, чем сам отказ (я живу в постоянном страхе, вместо единичного отказа)
- Саботируя себя, я гарантирую провал. Это самосбывающееся пророчество
- Я уже доказал что могу зарабатывать (был стабильный найм). Вопрос не в способностях, а в системе

**Новое убеждение:**
"Каждый завершенный проект - это данные. Мечта проверяется не одной попыткой, а серией экспериментов. Единственный способ достичь финансовой независимости - действовать, получать обратную связь, корректировать курс."

**Доказательства нового убеждения:**
- Все успешные предприниматели прошли через отказы (это данные, не приговор)
- У меня есть способности (была стабильность в найме)
- Текущая стратегия НЕ работает (годы без результата)
- Каждый проект дает опыт, связи, навыки - даже если не принес денег
- Финансовая независимость = система, а не один проект
- Чем быстрее получу "нет", тем быстрее найду "да"

**Практика:**
*Как я буду укреплять новое убеждение?*

**Эксперимент 1: Один завершенный проект**
```
┌─────────────────────────────────────────────────────┐
│  Выбрать ОДИН проект (самый близкий к завершению)   │
│         ↓                                            │
│  Завершить его (версия 1.0, не идеал)               │
│         ↓                                            │
│  Попытаться продать ОДНОМУ человеку                 │
│         ↓                                            │
│  Получить результат (да/нет + обратную связь)       │
│         ↓                                            │
│  Проанализировать: это приговор или данные?         │
└─────────────────────────────────────────────────────┘
```

Это не проверка всей мечты. Это проверка одной гипотезы.

**Правила эксперимента:**
- Срок: 2 недели на завершение
- Цель: не "идеальный продукт", а "работающая версия"
- Критерий: показал 1 человеку + получил обратную связь
- Успех = данные, не деньги (деньги - бонус, но цель - выйти из паралича)
